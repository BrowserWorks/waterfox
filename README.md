## 🌟 About / À propos

**[EN]** Foxxite is a revolutionary browser fork aiming to transform web navigation into a complete operating system experience. Completely decoupled from Mozilla's infrastructure, Foxxite uses a custom Cloudflare-based backend for synchronization, integrates Wireguard natively for per-tab VPN security, and features a highly adaptive UI.

**[FR]** Foxxite est un fork révolutionnaire visant à transformer la navigation web en une véritable expérience de système d'exploitation. Totalement découplé de l'infrastructure de Mozilla, Foxxite utilise un backend personnalisé basé sur Cloudflare pour la synchronisation, intègre Wireguard nativement pour une sécurité VPN par onglet, et propose une interface utilisateur hautement adaptative.

## ✨ Key Features / Fonctionnalités Clés

- **Absolute Sovereignty (Souveraineté Absolue)**: Zero telemetry to Mozilla. Custom Sync API powered by Cloudflare Workers.
- **Native Wireguard (Wireguard Natif)**: Built-in VPN capabilities directly in the network layer (`boringtun`/`wireguard-nt`).
- **High-Performance (Haute-Performance)**: Strictly compiled with `-march=native`, `-O3`, LTO, and PGO. Universal Android APK support.
- **Adaptive UI (Interface Adaptative)**: Dynamic CSS chrome injection based on website theme colors.
- **The "Bridge" (Le "Pont")**: Encrypted clipboard, Handoff, and P2P communication across your devices.
